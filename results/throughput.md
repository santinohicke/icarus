# Environment throughput

Agent decisions per second on the `realistic` task (3 physics ticks per decision), random actions, 5 s per measurement. Machine: Intel64 Family 6 Model 142 Stepping 9, GenuineIntel, 4 logical cores, Windows 10, Python 3.14.0. Generated by `training/benchmark.py`.

| Environment | Decisions/s | Physics ticks/s | vs. DummyVecEnv |
| --- | ---: | ---: | ---: |
| Gymnasium wrapper, one env stepped from Python | 135,026 | 405,077 | 2.0x |
| SB3 `DummyVecEnv` over 64 Gymnasium wrappers | 67,103 | 201,308 | 1.0x |
| `icarus.VecEnv`, 64 envs, one thread | 291,996 | 875,989 | 4.4x |
| `icarus.VecEnv`, 64 envs, every core | 467,878 | 1,403,635 | 7.0x |
| `IcarusVecEnv` (SB3 adapter), 64 envs, every core | 280,732 | 842,196 | 4.2x |

The Rust batch computes physics, observation, reward, termination and auto-reset for every environment in one call, with the GIL released; the Python rows pay one interpreter round trip per environment per decision.
